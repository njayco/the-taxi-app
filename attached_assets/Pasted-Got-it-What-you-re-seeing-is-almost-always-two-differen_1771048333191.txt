Got it. What you’re seeing is almost always two different “sources of truth” for lastSeen + a stale snapshot in the Driver Details panel.
	•	Drivers Live list is probably reading from a frequently-updated drivers array (polling every 1–3s).
	•	Driver Details is probably holding onto a copied driver object from when you first clicked the driver (or it fetched /api/drivers/:id once), and then it’s not being refreshed, so its lastSeen gets older and eventually flips to OFFLINE.

On top of that, there’s a second common bug: seconds vs milliseconds (or string parsing) when comparing Date.now() to lastSeen.

Here’s how to fix it cleanly.

⸻

Fix the OFFLINE bug (the correct architecture)

✅ Rule 1: Driver Details must “subscribe” to the same live driver object

Don’t store the whole driver object in state like:

setSelectedDriver(driver) // ❌ snapshot freezes

Instead store only the selectedDriverId:

setSelectedDriverId(driver.id) // ✅ stays live

Then derive the selected driver from the live list:

const selectedDriver = useMemo(
  () => drivers.find(d => d.id === selectedDriverId) ?? null,
  [drivers, selectedDriverId]
);

Now the Driver Details panel always renders the latest lastSeen.

⸻

Fix the OFFLINE calculation (seconds vs ms + clock drift)

✅ Use one helper everywhere

Pick ONE field type:
	•	Best: store lastSeenAt as an ISO string or ms timestamp
	•	Avoid storing “26s ago” strings in your data model (compute that in UI only)

Helper:

function computeDriverStatus(lastSeenAt: string | number | Date | null) {
  if (!lastSeenAt) return { status: "OFFLINE", ageMs: Infinity };

  const lastSeenMs =
    typeof lastSeenAt === "number"
      ? (lastSeenAt < 10_000_000_000 ? lastSeenAt * 1000 : lastSeenAt) // handles seconds vs ms
      : new Date(lastSeenAt).getTime();

  const nowMs = Date.now();
  const ageMs = Math.max(0, nowMs - lastSeenMs);

  // threshold: "online if seen in last 15s"
  const ONLINE_THRESHOLD_MS = 15_000;

  return { status: ageMs <= ONLINE_THRESHOLD_MS ? "ONLINE" : "OFFLINE", ageMs };
}

Use it in both Drivers Live list and Driver Details panel.
If you currently use different thresholds (like 10s in one place and 30s in the other), you’ll see mismatches.

⸻

Fix UI “Last seen: Xs ago” not updating

Even if lastSeenAt is correct, “Xs ago” will freeze unless something triggers re-render.

✅ Add a simple “tick” re-render every second

const [nowTick, setNowTick] = useState(0);

useEffect(() => {
  const t = setInterval(() => setNowTick(x => x + 1), 1000);
  return () => clearInterval(t);
}, []);

Then use nowTick (only) to force the “time ago” label to update.
